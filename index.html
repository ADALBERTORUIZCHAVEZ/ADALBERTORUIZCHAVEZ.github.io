Sobre mí

Una breve presentación de quién soy y qué puedo aportar.

¿Quién soy?

Soy una persona interesada en la tecnología y en aprender cómo se construyen los sistemas de software. A través de proyectos escolares he practicado la programación, el diseño de interfaces gráficas, el manejo de bases de datos y la comunicación entre aplicaciones.

¿Qué puedo hacer?

Puedo desarrollar programas con Java y Python, crear interfaces gráficas, conectar aplicaciones con bases de datos SQL y trabajar en proyectos que intercambian información mediante sockets. También puedo documentar proyectos y organizar su código usando Git y GitHub.
